# 장세 판정기 (market_signal)

## 구조 — 토큰을 쓰는 곳은 웹검색 1곳뿐

| 층 | 담당 | LLM 토큰 | 하는 일 |
|---|---|---|---|
| ① 수집 | `signals.py collect()` | 0 | FRED 13개 시리즈(공식), Yahoo(근사치: FRED보다 새 날짜 보충·코스피), 네이버(근사치: 외국인 순매매) |
| ② 리서치 | 서브에이전트 1개 (Sonnet) | 소 | 웹검색이 필요한 4항목(6·7·8·11) + 일정만 → `research.json` |
| ③ 판정 | `signals.py evaluate()` | 0 | 11개 신호, 악화 a~h, 위험 ①~⑤, 회복 R1~R6, 단계·시나리오 — 규칙 그대로 코드화 |
| ④ 출력 | `signals.py render()` | 0 | 한국어 리포트 → `out/latest_report.txt` |
| 오케스트레이터 | 스케줄 세션 | 소 | ②를 띄우고 ①③④ 실행, 결과 전달 |

## 실행

```bash
python3 market_signal/signals.py          # 리포트
python3 market_signal/signals.py --json   # 판정 내부값
```

## 규칙 해석 (요청문에 수치가 없어서 정한 것 — 바꾸려면 코드 수정)

- 9번 "대규모 순매도 지속" = 연속 순매도 5거래일 이상 또는 최근 20거래일 누적 −5조원 이하.
- 11번은 4사 중 1곳이라도 20% 미만이면 빨강(악화 f는 규칙대로 2곳 이상).
- 10번 근원 CPI는 BLS 발표처럼 소수 1자리 반올림 값으로 판정.
- 시나리오 "물가가 예상보다 낮음"은 컨센서스 대신 근원 CPI 0.2% 미만으로 대체.
- 회복 신호가 4개 이상이어도 위험 신호가 있으면 회복 1단계로 둠.
- 확인 불가(⚪) 신호는 빨강·켜짐 개수에 넣지 않음. 리서치 값의 기준일이 14일보다 오래되면 판정에서 뺌.
- 미국 동부 16:30 이전의 당일 Yahoo 값(장중 값)은 버림.
- FRED는 브라우저 User-Agent에 응답을 지연시켜서 curl UA로 요청함.
