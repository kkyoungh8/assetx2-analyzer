## 1. 무엇을 만드나

나폴레온 힐 『생각하라 그리고 부자가 되어라』의 흐름 **확고한 목적 → 계획 → 즉시 실행 → 끈기(점검과 재계획)** 을 매일 굴리는, 나 혼자 쓰는 앱이다. 투자(자산제곱)는 목적을 이루는 수단 가운데 하나로 이 안에 들어간다.

```
                    🎯 확고한 목적 (금액·기한·대가) ← 4단계 코칭
        ┌──────────────┬───────────┴───────────┬────────────────────┐
   💼 버는 돈        💳 쓰는 돈              📈 불리는 돈            📰 판단 재료
   (제안·부수입)     (카드 문자·카톡)          (토스·미래에셋)          (마켓리서치 채널·주 2회 리포트)
        └──────────────┴───────────┬───────────┴────────────────────┘
                           🧮 순자산 · 목표 진척 · 저축률
                                   ▼
              🔁 매일(문장·습관) · 매주(점검·재계획) · 리포트마다(전략 갱신)
```

1. 수집과 해석을 나눈다. 원문은 `raw_events`에 그대로 두고, 해석 규칙이 바뀌면 다시 처리한다.

3. 개인 데이터는 저장소 밖 `~/.richcoach/`에 둔다 (DB, 비밀값, 텔레그램 세션).

## 5. 실행 환경 (맥북)

- **웹앱:** `streamlit run app.py` → `http://localhost:8501`. 휴대폰에서 볼 일은 텔레그램 봇이 맡는다.
- **수집기:** macOS `launchd` LaunchAgent로 로그인할 때 자동으로 시작하고, 꺼지면 다시 띄운다. 맥북이 잠자는 동안에는 수집이 멈춘다 → 깨어나면 놓친 메시지를 이어서 받는다 (텔레그램 사용자 API는 지난 메시지 조회 가능 `[확인 필요]`).
- **저장소 비공개 전환 영향:** 기존 분석기는 전략 파일을 `raw.githubusercontent.com`에서 인증 없이 읽는다 → 비공개가 되면 못 읽는다. P2에서 전략을 로컬 DB에서 읽도록 바꾸면 해결된다. Streamlit Cloud에 배포해 둔 앱이 있다면 그쪽도 영향을 받는다 `[확인 필요]`.

## 6. 외부 데이터 연결

### 6-1. 자산제곱 마켓리서치 채널 — 실시간 (P3)
- **방법:** 텔레그램 **사용자 계정 API** (Telethon). 내가 구독한 채널이면 공개·비공개와 상관없이 읽을 수 있다. my.telegram.org에서 api_id/api_hash를 발급받고, 맥북에서 한 번 로그인하면 `~/.richcoach/telegram.session`에 세션이 저장된다.
- **흐름:** 새 메시지 → `raw_events` 저장 → **관련성 판정**(내 보유 종목·관심 종목·전략 키워드와 겹치는지. 규칙으로 먼저 거르고 애매한 것만 AI) → 중요하면 **봇이 즉시 휴대폰으로 알림** ("보유 종목 ○○ 관련: 요약 + 현재 5존 상태") → 하루 요약은 전략 화면과 주간 점검에 반영한다.
- **주의:** 유료 채널 내용은 **개인 판단용으로만** 저장하고 밖으로 내보내지 않는다.

### 6-2. 주 2회 전략 리포트 (PDF) — 전략의 뼈대 (P2)
- **저장:** 리포트를 PDF로 출력해 **정해진 폴더**(예: `~/.richcoach/reports/inbox`, 또는 지금 쓰는 Obsidian '자산제곱' 폴더)에 넣는다.
- **읽기 — 기존 방식의 문제를 고친다:** 지금 파이프라인은 `pdfminer`로 텍스트를 최대 5,000자까지만 뽑는다. 실제로 지난 리포트 두 건은 36쪽 중 약 2쪽, 22쪽 중 약 2쪽만 분석됐다 (`strategy/current_strategy.md`에 기록됨). 또 '복사 방지' 페이지를 출력한 PDF는 글자가 아니라 이미지일 수도 있다 `[확인 필요]`.
  → **PDF 파일 전체를 Claude에 그대로 넣는다** (Claude API는 PDF를 직접 읽음, 문서당 최대 600쪽·32MB). 텍스트로 된 PDF든 이미지로 된 PDF든 쪽 수를 자르지 않고 읽는다.
- **전략 갱신 방식 (살아 있는 전략 문서):**
  1. 리포트 하나 → **구조화 요약**: 시장 국면, 핵심 논리, 주목 테마·자산, 위험 요인, 행동 제안, 원문 쪽 번호
  2. **이전 전략 + 새 리포트 → 새 전략 버전.** "무엇이 바뀌었나"를 따로 적는다 (유지 / 강화 / 약화 / 폐기)
  3. 버전마다 DB에 남긴다 → 전략이 어떻게 변해 왔는지 시간순으로 본다
  4. 새 전략 × **내 두 계좌 보유 종목** → "전략과 맞는 종목 / 어긋나는 종목 / 비중 점검"
- **자동화:** 폴더 감시(launchd `WatchPaths`)로 PDF가 들어오면 자동 처리 → 끝나면 봇이 "새 전략 버전 v12: 바뀐 점 3줄"을 보낸다.

### 6-3. 카드 사용 알림 — 문자 + 카카오톡, 아이폰 (P4)
입구를 하나로 모은다: **나만 있는 비공개 텔레그램 채널 "카드 수신함"** → 맥북 수집기(6-1과 같은 사용자 API)가 읽는다.

| 알림 경로 | 수신함으로 보내는 방법 |
|---|---|
| **문자(SMS)** | 아이폰 **단축어 → 개인용 자동화 → '메시지' 트리거**(발신자나 '승인' 같은 키워드) → URL 가져오기 동작으로 봇 API를 호출해 수신함 채널에 원문을 올린다. 확인 없이 바로 실행되는지는 iOS 버전에 따라 다르다 `[확인 필요]` |
| **카카오톡 알림톡** | 아이폰은 카카오톡 메시지를 자동으로 읽어 넘길 방법이 없다 `[확인 필요]`. 그래서 ① 그 카드사의 알림을 **문자로 바꿀 수 있는지** 먼저 확인하고 (유료일 수 있음 `[확인 필요]`), ② 안 되면 알림을 길게 눌러 **공유 → '카드 보내기' 단축어**로 한 번에 보내고, ③ **월말에 카드사 내역 파일**을 올려 빠진 건을 맞춘다 |

- 파싱: 카드사별 파서 (순수 함수 + 실제 문자 샘플 테스트) → `{일시, 가맹점, 금액, 카드, 승인/취소, 할부}` → 분류(규칙 먼저, 남는 것만 AI)
- 연결: 월 잉여자금 → 코칭 3단계 "쓸 수 있는 자금" / 주간 점검 / 순자산

### 6-4. 증권 계좌 — 토스증권 + 미래에셋 (P2)
- 개인이 바로 쓸 수 있는 보유 종목 조회 API가 있는지 확인되지 않았다 `[확인 필요]` → **1차는 화면 캡처 인식**(기존 기능)을 **계좌별로** 쓴다. 증권사 앱 보유 종목 화면을 캡처해 올리면, 계좌를 고르고 인식 결과를 확인한 뒤 저장한다.
- 계좌별 보유 종목, 예수금(현금)을 저장한다 → 슬라이더 대신 **실제 현금 비중**으로 5존을 판정하고, 계좌 합산 화면과 계좌별 화면을 둔다.
- 분석할 때마다 스냅샷을 남긴다 → 순자산 추이 (P5).

## 7. 자산제곱(invest) 재설계 — 유지할 것과 바꿀 것
- **유지:** 종목명 검색(네이버·Yahoo), 캡처 인식, 실시간 시세(네이버·yfinance), 환율, 5존·52주 판정, TradingView 차트, AI 종합 분석, 전략 딥다이브 대화
- **바꿈:** 1,100줄 한 파일 → 모듈 분리 + 5존 테스트 / 계좌 2개 / 보유 종목·예수금 저장 / 전략을 GitHub 파일 대신 **DB의 전략 버전**에서 읽음 / AI 분석에 **확고한 목적**과 **마켓리서치 최근 요약**을 함께 넣음 / 모델 호출을 `ai/client.py`로 통일

| P4 가계부 | 카드 수신함, 문자 단축어, 카톡 공유 단축어, 파서 | 실제 카드 문자 10건 이상 정확히 파싱 | |
